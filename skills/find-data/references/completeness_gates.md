# Completeness gates — find-data's pass/warn/fail criteria

These are the four gates `find-data` runs before declaring a dataset folder
ready for `/data2story`. They are intentionally CHEAP (file I/O + HTTP HEAD,
no LLM judgment in the deterministic layer) — narrative-quality checks
happen later, inside Detective.

Thresholds are codified in `tools/audit.py`. Tune there, not in prose.

---

## Gate 1 — Technical (any fail blocks the folder)

Implemented in `audit.py::evaluate_gates` under `g1_*`.

| Check | Verdict if it fails | Reason |
|---|---|---|
| ≥ 1 parseable data file (csv/xlsx/json/tsv) | **fail** | No data → nothing to analyse |
| File size > 0 bytes | **fail** | Empty file |
| CSV parses without exceptions | **fail** | Detective's `pd.read_csv` will crash |
| File size ≤ 50 MB | **warn** | Designer/Programmer may stall; large files often hide raw dumps |
| UTF-8 encoding (latin-1 fallback OK) | **warn** | Cross-platform issues downstream |

**Hard rule**: if ANY check in this gate fails, `find-data` will NOT mark the
folder ready, regardless of how the other gates score.

---

## Gate 2 — Story material (≥ 3 warnings → fail)

Implemented in `audit.py::evaluate_gates` under `g2_*`.

| Check | Verdict if it fails | Reason |
|---|---|---|
| ≥ 50 rows in primary CSV | **warn** | Tiny tables can still ship (case study) but should be flagged |
| ≥ 1 numeric metric column | **warn** | Without a numeric variable, Analyst has nothing to compute |
| ≥ 1 dimension of variation (entity/year/category) | **warn** | A flat single-row table can't support contrast |
| Primary metric non-null rate > 50% | **warn** | Too much missingness → unreliable claims |
| If time-series: declared time range matches actual `year_min/year_max` | **warn** | README lies → Detective will write false context |

Three or more warnings → escalate to **fail**. Tunable in `audit.py:MIN_ROWS` etc.

---

## Gate 3 — Provenance (≥ 3 warnings → fail)

Implemented in `audit.py::evaluate_gates` under `g3_*`.

| Check | Verdict if it fails | Reason |
|---|---|---|
| README.md exists | **fail** | No README → Detective cannot ground its `det_xx` claims |
| README contains a codebook table | **warn** | Column meanings ambiguous |
| README mentions a source ("source", "data from", "collected by") OR ≥ 1 URL | **warn** | Provenance unverifiable |
| ≥ 1 URL in README HEAD-checks as alive | **warn** | Dead source links → can't cite |

Three or more warnings → escalate to **fail**.

If README is auto-generated by `find-data` (template), it MUST be filled in
before re-running the audit — the template's placeholders fail this gate.

---

## Gate 4 — Multimodal-ready (advisory, never fails)

Performed by the SKILL.md agent itself, not by `audit.py` (requires LLM
classification of subjects).

| Class | Verdict | What it means for Designer |
|---|---|---|
| **Concrete subjects exist** (people/places/species/events/objects) AND ≥ 1 reference image findable on Wikimedia Commons | **pass** | Designer can fetch reference photos as per `data2story/skill/detective/SKILL.md:46-72` |
| **Concrete subjects exist** but reference images not found in quick search | **warn** | Designer will work harder; flag in `validate.json` |
| **Abstract data** (rates, indices, generic counts, derived metrics) | **pass — exempted** | Designer will use charts only; no penalty |

This gate exists to surface multimodal-readiness EARLY so the user sees
"this will be a chart-only blog" before running the full pipeline.

It is intentionally non-blocking — even a fully abstract dataset can produce
a good Data2Story blog (see industrial_revolutions, which is mostly OWID
time series).

---

## How a folder passes overall

```
overall.ready_for_data2story = True
iff
  gates.technical.verdict      != "fail"
  AND gates.story_material.verdict  != "fail"
  AND gates.provenance.verdict      != "fail"
```

(Gate 4 is advisory only — never blocks.)

`validate.json` is written alongside the data files. The Detective role
later reads this file to know what to focus on (e.g., if Gate 2 warned
about low non-null rate, Detective will flag that for the reader).
